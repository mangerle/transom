核心优势

终端、文件与连接，不再分散在多个工具里

Transom 把日常运维中反复切换的现场收进同一窗口。会话状态与标签页同生命周期，文件面板跟随 Shell 的当前目录，所有网络链路都由 Rust 原生处理。

01

原生渲染，不嵌网页

终端网格由 GPUI 与真实字体引擎绘制，不打包 Chromium。高频重绘、中文双宽对齐与主题切换都留在原生进程内。

GPU 加速的桌面体验
02

工作区按现场组织

标签内自由切分，每一刀都能独立指定方向；单窗格可以最大化或拆成新标签。远端主机、本地终端与串口可以并排观察。

可嵌套的分屏布局
03

本地优先的安全边界

口令与私钥 passphrase 进入操作系统钥匙串；会话文件原子写入并限制权限。审计留档默认关闭，开启后按连接逐份落盘。

凭证不进入明文配置
终端工作区

一个标签页，容纳整场排障

分隔方向属于每一刀，窗格可以继续嵌套。把日志、复现命令与设备串口放在同一视图里，不必在多个终端窗口之间来回定位。

  • 标签、窗格与 SFTP 面板各自持有独立会话状态。
  • 快速打开面板支持输入 deploy@10.0.0.8:2222 免保存直连。
  • 启动时恢复并重连上次会话，多级文件夹与批量属性修改同步可用。
  • 凭据模板让多个会话共享一个账号，改密只需更新一处。

连接与安全

连接是原生的，凭证也留在本机

SSH2 由 russh 处理，串口与本地 PTY 走独立适配层。Transom 不把凭证塞进配置文件，也不在日志里留下明文密码。

  • 密码、键盘交互、公钥、OpenSSH CA 用户证书与 ssh-agent 认证。
  • 端口转发覆盖本地、远程与动态 SOCKS5，可随时启停并查看通道状态。
  • 批量 TCP 拨测与 Wake-on-LAN，适合成组主机巡检。
  • 会话库支持明文 JSON/YAML 与 Argon2id + XChaCha20-Poly1305 加密备份。
SFTP 文件

终端与文件，共享同一个当前目录

本地与远程双栏浏览、断点续传、差异同步和远程编辑都在工作台里完成。文件面板跟随 Shell 的目录变化，拖进终端即可上传到会话当前位置。

  • 传输队列支持置顶插队、失败重试、速率、百分比与完成后批量清理。
  • 按大小与修改时间做目录差异比较，勾选后执行增量同步。
  • 可选 SHA-256 分块校验，上传目录支持通配符排除规则。
  • 远程编辑器提供保存前 diff 预览、自动备份与 chmod 九宫格输入。

终端效率

查找、补全与历史，都围绕光标工作

缓冲区全文检索带正则开关，右侧刻度显示所有命中位置。命令历史从 shell 集成标记采集，边输入边给出建议。

  • 常驻高亮 ERROR、WARN、INFO、DEBUG、IPv4 与 UUID，颜色跟随主题。
  • 输入时展示历史建议，Tab 补全第一条，回车仍执行当前输入。
  • Alt + 拖拽矩形列选，可自定义双击选词分隔符。
  • 命令耗时超过阈值时通过 OSC 133 / OSC 777 发出桌面通知。

Transom 会打包浏览器内核吗？

不会。界面使用 GPUI 原生渲染，终端仿真来自 alacritty_terminal，不存在 Electron 或内置 Chromium 运行时。

会话密码保存在哪里？

密码和私钥 passphrase 存入操作系统钥匙串，服务名为 transom。会话文件只保存连接配置与钥匙串槽位引用。

Windows 与 macOS 可以日常使用吗？

项目已为三端提供构建与发布产物，但 Linux 是主要验证平台。Windows 与 macOS 仍缺少充分的真实桌面人工交互验证，请按实验性功能评估。

如何配置自动更新？

应用内「偏好设置 → 关于 → 软件更新」会检查签名清单、下载并验证安装包。连续两次启动失败会回滚到上一版本。

SFTP 会自动跟随终端目录吗？

会。SFTP 自动跟随 Shell 的当前工作目录，每个标签页持有各自的远程会话状态；也可以手动导航到其他路径。
