# Transom 功能特性全景与落地路线图 (Features & Roadmap)

本文档基于成熟现代商业终端的全部实用特性，结合 Transom 当前技术架构（Rust + GPUI 渲染 + russh + alacritty_terminal + russh-sftp），**已全面剔除过时落后与存在安全隐患的旧技术**。

文档分为 **终端与 Shell (Terminal / Shell / SSH)** 与 **远程文件传输 (SFTP / Transfer)** 两大模块。表格最后一列明确标明当前完成状态：
- **【已完成】**：Transom 当前工程代码库中已经开发实现并可稳定运行的功能。
- **【原生支持】**：基于 alacritty_terminal 内核引擎与 GPUI 跨平台图形底层原生已具备的工业级标准能力。
- **【待实现 (P0/P1/P2)】**：计划在后续敏捷迭代中推进落地的新特性（按优先级由高到低）。
