# IntelliJ New UI 操作图标

- 来源：IntelliJ IDEA 2026.3，构建号 `263.7307.200` 的
  `intellij.platform.icons.jar`，目录为 `expui/actions`、`expui/general`、
  `expui/vcs`、`expui/nodes`、`expui/ide`、`expui/gutter`、`expui/run`、
  `expui/windows` 和 `expui/toolwindows`。
- 官方目录：<https://intellij-icons.jetbrains.design/>
- 许可：带版权头的 SVG 原样保留 JetBrains Apache 2.0 声明。
- `help`、`keyboard`、`layout`、`desktop` 来自 `expui/general` 或
  `expui/nodes`；`project` 来自 `expui/toolwindows`，均使用官方图标站提供的
  明暗两套 SVG。
- `vcs` 是 Git 身份、分支与远端分支的统一图标；`refreshAuto` 作为“自动”选项图标，避免与服务器图标重复。
- `realIntentionBulb`、`show` 用于 SFTP 编辑与隐藏文件开关。
- `exceptionAnalyzer` 来自 `ExceptionAnalyzerIcons/expui`，用于会话列表拨测按钮；原文件未内嵌版权头，升级时需复核插件资产许可。
