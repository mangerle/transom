- 官方图标目录：<https://intellij-icons.jetbrains.design/>

- Rust 语言图标：IntelliJ Community 的 `language/rust.svg` 与 `rust_dark.svg`。
- 语言插件图标：官方图标站中的 Python、Kotlin、Go、PHP、Ruby、Scala、Dart、
  Swift、Lua、Haskell、Elixir、Erlang、Clojure、R、Julia、Zig、Objective-C、

  `ToolboxPlatformFileTypeImagesAssetsIcons/file-types`；这些文件仍保留在上游
  JetBrains 图标集中，升级或再分发时应结合图标站说明复核许可。
