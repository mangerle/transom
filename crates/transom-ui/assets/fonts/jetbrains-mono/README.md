# JetBrains Mono

- 版本：2.304
- 上游项目：https://github.com/JetBrains/JetBrainsMono
- 发布包：https://github.com/JetBrains/JetBrainsMono/releases/download/v2.304/JetBrainsMono-2.304.zip
- 许可证：SIL Open Font License 1.1，完整文本见同目录 `OFL.txt`

应用内嵌以下四个 TTF 文件，用于终端常规、粗体、斜体与粗斜体字形：

- `JetBrainsMono-Regular.ttf`
- `JetBrainsMono-Bold.ttf`
- `JetBrainsMono-Italic.ttf`
- `JetBrainsMono-BoldItalic.ttf`

发布包内同时通过 `licenses/JetBrainsMono-OFL.txt`（cargo-packager）和
`/usr/share/doc/transom/fonts/JetBrainsMono-OFL.txt`（DEB）携带许可证。
